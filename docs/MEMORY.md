# Multi-Tier Cognitive Memory Architecture

## 1. Memory Tiers
1. **Short-Term Memory**: Active conversation context, current dialogue turns, active task ID, and pending clarifications.
2. **Episodic Memory**: History of executed missions (task ID, action, target, destination, result, duration, failure modes).
3. **Semantic Memory**: Persistent physical priors (dimensions, weights, grasp vectors), workstation coordinates, and tool registry.
4. **Robot Memory**: Hardware health records, battery discharge curves, motor faults, and maintenance logs.
