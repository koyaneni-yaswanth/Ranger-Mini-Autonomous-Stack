# Physical Ranger Mini Hardware Interface

- **UGV Base**: AgileX Ranger Mini 2.0 (4WIS & Skid modes).
- **CAN Bus**: SocketCAN interface `can0` at 500k baud.
- **LiDAR**: Livox MID-360 (Ethernet UDP PointCloud2).
- **Camera**: Intel RealSense D435 (USB 3.0 RGB-D).
- **IMU**: 9-DOF IMU integrated on CAN/Livox.
